# Power BI Dashboard Implementation Guide
## Project 23: Music Streaming Trends Analysis

> **Note:** `.pbix` files are proprietary binary archives generated by **Power BI Desktop** on Windows. Use this guide together with the exported star-schema CSVs (`data/cleaned/*.csv`) or the Oracle views (`sql/04_analytical_views.sql`) and `powerbi/dax_measures.dax` to build and save `Music_Streaming_Trends_Dashboard.pbix`.

---

## 1. Data Model (Star Schema)

1. Open **Power BI Desktop** -> **Get Data** -> either:
   - **Oracle Database** (connect to your Oracle instance and select `DIM_ARTIST`, `DIM_GENRE`, `DIM_DATE`, `FACT_TRACK_STREAM` or the `VW_*` views), OR
   - **Text/CSV** and load the 4 cleaned star-schema files from `data/cleaned/`:
     - `dim_artists.csv`
     - `dim_genres.csv`
     - `dim_dates.csv`
     - `fact_streams.csv`
2. In **Model View**, verify `1 : Many` single-direction relationships:
   - `dim_artists[artist_id]` -> `fact_streams[artist_id]`
   - `dim_genres[genre_id]` -> `fact_streams[genre_id]`
   - `dim_dates[date_id]` -> `fact_streams[date_id]`
3. Create a **Date Hierarchy** on `dim_dates`: `release_year` -> `release_quarter` -> `month_name`.
4. Create a **Music Hierarchy**: `dim_genres[genre_name]` -> `dim_artists[artist_name]` -> `fact_streams[track_name]`.

---

## 2. Slicers (Global / Synced Across Pages)

Add the following **4 Slicers** to the top/left filter rail and sync across all pages:
1. **Release Year** (`dim_dates[release_year]`, Between / Dropdown)
2. **Genre** (`dim_genres[genre_name]`, Multi-select Dropdown)
3. **Artist Tier** (`dim_artists[artist_tier]`, Tile / List)
4. **Explicit Flag** (`fact_streams[explicit_flag]`, Tile: `Y` / `N`)

---

## 3. Dashboard Pages & Visuals

### Page 1: Executive Streaming Overview
- **5 KPI Cards**:
  - `Total Streams (Billions)`
  - `Total Tracks`
  - `Total Artists`
  - `Avg Popularity`
  - `Explicit Track %`
- **Horizontal Bar Chart**: Top 10 Artists by `Total Streams` (filter Visual-level `Artist Stream Rank <= 10`, with drill-through to Artist Detail).
- **Donut / Treemap**: `Total Streams` by `dim_genres[genre_name]`.
- **Line & Clustered Column Chart**: Yearly `Total Streams` (bars) vs `Avg Popularity` (line) with drill-down from `Year -> Quarter -> Month`.

### Page 2: Audio-Feature Trends (2015–2025)
- **Multi-Line Chart**: `Avg Danceability`, `Avg Energy`, `Avg Valence`, `Avg Acousticness` over `dim_dates[release_year]`.
- **Combo Chart**: `Avg Duration (Min)` & `Avg Tempo (BPM)` by `release_year`.
- **Matrix Visual**: Genre vs Audio Features (`Avg Danceability`, `Avg Energy`, `Avg Valence`, `Avg Loudness`, `Avg Popularity`) with conditional formatting data bars.

### Page 3: Feature-to-Popularity Correlation & Drill-Down
- **Scatter Plot**: X = `Danceability`, Y = `Popularity`, Size = `Total Streams`, Legend = `Genre`, with trend line enabled.
- **Scatter Plot**: X = `Loudness (dB)`, Y = `Popularity` (or `Acousticness` vs `Popularity`).
- **Detail Table (Drill-Down)**: `Genre -> Artist -> Track` showing `Streams`, `Popularity`, `Danceability`, `Energy`, `Release Date`.
